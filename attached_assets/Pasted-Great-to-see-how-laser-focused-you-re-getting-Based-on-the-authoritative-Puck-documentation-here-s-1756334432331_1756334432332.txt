Fix Plan (Step-by-Step)
Step 1: Ensure CSS is Loaded

Double-check that your Puck editor component (probably puck-editor.tsx or similar) begins with:

import "@measured/puck/puck.css";

Step 2: Add root in the Puck Config

Update your puck-config.tsx to include a root section like:

import type { Config } from "@measured/puck";

export const config: Config = {
  components: {
    HeroSection,
    TypesSection,
    // ...other components
  },
  root: {
    fields: {
      title: { type: "text" },
    },
    defaultProps: {
      title: "Homepage",
    },
    render: ({ children, title }) => (
      <div data-title={title}>
        {children}
      </div>
    ),
  },
};


This ensures Puck renders the page container and metadata correctly. 
puckeditor.com

Step 3: Adjust Type Definitions

If you're using TypeScript, ensure your UserConfig includes the root props, so types align with the config:

type UserConfig = {
  HeroSection: ComponentPropsForHero;
  TypesSection: ComponentPropsForTypes;
};

type RootProps = {
  title: string;
};

const config: Config<UserConfig, RootProps> = { /* ... */ };


This will prevent silent mismatches between what Puck expects and what you're providing.

Step 4: Test with Minimal Data

Start with a minimal data set to confirm everything works:

{
  "content": [
    { "type": "HeroSection", "props": {} }
  ],
  "root": { "props": { "title": "Test" } }
}


If this renders, your canvas is alive—and you can then restore the full page content confidently.

Step 5: Verify Full Functionality

Once the minimal setup works, revert to your full homepage content. Confirm:
